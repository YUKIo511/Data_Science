# Data Science & Research Literacy: English, Math & Python

This repository is an ultra-practical learning and experimentation hub based on the Microsoft official curriculum, *Data Science for Beginners*. The core objective is to holistically develop three essential pillars: **English proficiency for fluently decoding cutting-edge research papers**, **mathematical theories for uncovering the essence of data**, and **implementation skills using Python**.

Rather than simply copying and running provided code snippet templates, this repository embraces a rigorous approach—dissecting lines of code step-by-step to understand "why a specific process is necessary" and "how it connects to underlying theoretical frameworks in research and statistics."

## 🧭 Learning Concepts (The Three Pillars)

### 1. 🌐 English & Research Literacy (Paper Comprehension & Primary Source Decoding)
To consistently stay at the forefront of the data science field, "research literacy"—the ability to fluently read academic papers—is indispensable. 
In this repository, I thoroughly digest the fine nuances and contexts of specialized English expressions found in the curriculum (e.g., `derivative, or daily difference in new cases`). By doing so, I am proactively building a robust linguistic foundation and reading stamina required to smoothly and accurately ingest genuine international research papers in the near future.

### 2. 📐 Math & Statistics (Mathematical Theory & Verbalization)
I refuse to treat code as a black box; instead, I verbalize the underlying meaning behind mathematical formulas. 
For instance, in calculating the Effective Reproduction Number ($R_t$), I mathematically analyze how a division-by-zero anomaly caused by a sharp drop in data impacts the visualization (such as generating infinity `inf` or data `gaps`). This cultivates a precise analytical eye that never confuses volume (total counts) with scale (multipliers), allowing for critical reading of metrics in research papers.

### 3. 🐍 Python (Real-World Code Implementation)
When encountering outdated code from the curriculum that causes errors in modern environments (e.g., the deprecation of `fillna(method='pad')` and the transition to the latest `.ffill()`), I independently consult official documentation (Pandas/NumPy) to debug. Furthermore, I practice tailoring visualizations to real-world data characteristics, such as refining graph boundaries (`set_ylim`), to hone practical implementation skills.
